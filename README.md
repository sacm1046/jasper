# DOCUMENTACIÓN


### Dependencias
1. Versión de Java: 6
2. Versión JasperReports: 5.6.0

### Instrucciones
1. Agrega el archivo .jrxml a la carpeta reports
2. Se generará un .jasper por cada archivo en reports
3. Los archivos resultantes estarán disponible una vez el workflow se haya ejecutado en los actions de Github, en la sección artifacts se encontrará una carpeta llamada compiled_reports con el contenido deseado.
