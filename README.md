# DOCUMENTACIÓN

### Dependencias
1. Versión de Java: 6
2. Versión JasperReports: 5.6.0

### Instrucciones
1. Agrega el archivo .jrxml a compilar en el directorio reports.
2. Se generará compilado .jasper por cada archivo en el directorio reports.
3. Los archivos resultantes estarán disponible una vez el workflow se haya ejecutado conéxito en los actions de Github. En la sección artifacts se encontrará una carpeta llamada compiled_reports con el contenido deseado.
